Add Footer Plugin to Any HTML Website

Follow these simple steps to embed the footer plugin into any HTML, WordPress, React, or static site in under 3 lines of code.

Step 1: Include Script & Web Component

Paste this snippet right before the closing </body> tag of your HTML document:

<!-- Site Footer Plugin -->
<script src="https://cdn.tailwindcss.com"></script>
<script src="footer-plugin.js"></script>
<site-footer></site-footer>
Step 2: Standalone Component Source (`footer-plugin.js`)

Save this file as footer-plugin.js on your server:
